# Kenney assets (CC0)

Модели в этой папке взяты из официальных стартовых наборов Kenney для Godot
(github.com/KenneyNL): Starter Kit City Builder, Starter Kit 3D Platformer,
Starter Kit Racing. Ассеты в этих наборах распространяются по лицензии
CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/), атрибуция не
обязательна, но приветствуется: Kenney (www.kenney.nl).
