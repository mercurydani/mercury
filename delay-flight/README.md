# Задержка рейса

Кооп-хаос на перроне для 1–4 игроков (Godot 4.3). Вы — наземная служба аэропорта: грузите багаж,
заправляете самолёты и не даёте им задерживаться. Если рейс стоит слишком долго, растёт «злость»,
и на перрон выходят пилоты, диспетчеры, пилоты-хулиганы и — с малым шансом — гипернакачанный КАЧОК.

## Запуск
Откройте папку в Godot 4.3+ и нажмите F5, либо:

    godot --path delay-flight

## Управление
| Игрок | Роль | Движение | Действие |
|---|---|---|---|
| P1 | Грузчик | WASD | Пробел |
| P2 | Заправщик | Стрелки | Enter |
| P3 | Маршалер | Геймпад 1, левый стик | A |
| P4 | Механик | Геймпад 2, левый стик | A |

Действие: взять чемодан / кофе / бургер, сдать чемодан у носа самолёта. Держать у крыла — заправка.
Кофе успокаивает пилота и диспетчера, бургер — КАЧКА.

## Проверка
    godot --headless --path delay-flight --script tests/sim.gd   # прогон логики смены
    xvfb-run -a godot --path delay-flight --rendering-driver opengl3 --script tests/shot.gd   # скриншоты в /tmp
